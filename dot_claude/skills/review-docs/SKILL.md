name: review-docs
description: Audit product documentation coherence against the codebase. Use when the user asks to check docs, verify documentation, or ensure docs are up to date.
---

Launch the pm-review agent in audit mode to check documentation coherence against the current codebase.

This verifies:
- Glossary terms match code naming.
- Business rules are enforced in code.
- Design system tokens match Tailwind config.
- Context map matches folder structure.
- No stale or missing documents.
