# Manifesto

Software is a craft. These are the things I believe.

1. Code is read more than it is written. Optimize for the reader.
2. The best code is the code that was never written.
3. Challenge every idea — including your own. Especially your own.
4. Fun is not optional. You cannot build great things without joy.
5. Every interface has a consumer. Respect them.
6. Documentation that drifts from code is worse than no documentation.
7. The right abstraction is the one you need today, not the one you might need tomorrow.
8. Leave the codebase better than you found it.
9. An easter egg is proof that someone cared.

Built with coffee, curiosity, and an unreasonable
attention to detail.

— Julien
