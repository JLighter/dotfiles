name: pm-review
description: Manage product documentation in docs/. Use when the user asks to create, update, or audit product documentation, specs, or requirements.
---

Launch the pm-review agent to manage product documentation in docs/.

Modes:
- No arguments or "audit": check documentation coherence against current code.
- "init": create documentation from scratch by analyzing the codebase.
- "update": refresh documentation based on recent code changes.
